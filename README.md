# 藉口生成器 / Excuse Me

Describe a situation, pick a style, and let a cartoon Chinese immortal hand you an excuse engraved on a plaque.

**Live site:** https://excuseme852.github.io

- Static website: plain HTML, CSS, and JavaScript, hosted free on GitHub Pages.
- Excuses come from a pre-written library and are picked in your browser.
- What you type stays on your device. Nothing is sent anywhere.

## Project layout

- `docs/`: the website (GitHub Pages publishes this folder; it is not documentation)
- `spec/`: product specification
- `CLAUDE.md`, `PROGRESS.md`: working notes for development

## Run locally

Open the folder in Cursor, right-click `docs/index.html`, and choose **Open with Live Server**.
